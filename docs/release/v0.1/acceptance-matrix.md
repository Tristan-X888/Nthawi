# Nthawi release acceptance matrix v0.1

Date: 3 November 2026 (Africa/Blantyre).
Inputs: [specification](specification.md), [decision register](decisions.md).

**Document acceptance** below is the Step 2.1 check: traceable coverage with
truthful status and explicit dependencies. It can pass when a product choice
is deliberately Open. **Future evidence** is a proposed verification method
for a later authorized phase; it is not executed or passed in Step 2.1.
Scope approval is not implementation acceptance. No row authorizes implementation.

Source IDs are defined in the decision register. RS identifiers refer to
specification sections. The user/product owner approves product decisions;
a future implementer supplies product evidence; the Step 2.1 executor checks
these documents. No additional person is assigned.
