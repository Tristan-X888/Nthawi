# Nthawi release specifications

The current release contract is
[edition 0.3: approved Phase 2 release contract](v0.3/release-specification.md).
The product owner approved the complete edition 0.2 contract with launch-plan
amendments: **MWK 20,000.00 gross per 30-day term and 2 active workspaces**,
with every other edition 0.2 allowance and rule unchanged. Edition 0.3 records
that approval, the resulting decision statuses and the acceptance-matrix delta.

Read the editions in order. Edition 0.3 incorporates the
[edition 0.2 release specification](v0.2/release-specification.md), which
incorporates the [v0.1 specification](v0.1/specification.md),
[decision register](v0.1/decisions.md) and
[acceptance matrix](v0.1/acceptance-matrix.md). Earlier editions are preserved
as dated snapshots; a later edition supersedes them only where it says so.

Phase 2's decision gate is satisfied in documentation. Repository acceptance
still requires independent approving GitHub review of PR #5's final head,
resolved review threads, current required checks and the user's explicit merge
instruction. Phase 3 begins only on the user's next command.

Scope/product approval, technical review, hosted checks, independent approving
GitHub review and merge authorization are separate facts. No release
specification constitutes implemented product behavior, service readiness, a
provider purchase or permission to merge/deploy.
