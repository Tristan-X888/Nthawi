# Nthawi release specifications

The current candidate is
[edition 0.2: Phase 2 closure proposal](v0.2/release-specification.md).
It records the owner's newly approved languages and four engineering targets,
and a complete **unapproved** commercial/contract package for review.
**Phase 2 is not yet complete.**

Edition 0.2 incorporates the
[v0.1 specification](v0.1/specification.md),
[decision register](v0.1/decisions.md) and
[acceptance matrix](v0.1/acceptance-matrix.md), then applies its explicit
decision/matrix delta. Edition 0.1 is preserved as the published Step 2.1
snapshot; its older language/target deferrals are superseded only where the
new current user answers are cited.

Use the edition 0.2 completion gate to distinguish required release decisions
from later merchant, parser, AI and operational feasibility evidence.
Scope/product approval, technical review, hosted checks, independent approving
GitHub review and merge authorization are separate facts.

No release specification constitutes implemented product behavior, service
readiness, a provider purchase or permission to merge/deploy.
